## S12 IMAGE SPEC FORMAT

Use exactly this structure per image. No extra fields. No generation prompts.

```
IMG[N] type: featured|in-body
1. purpose   : [one sentence ΓÇö why this image exists]
2. subject   : [specific subject ΓÇö not vague]
3. tone      : [emotional register: warm / clinical / alarming / inspiring]
4. placement : [H2 section name + before/after which paragraph]
5. alt       : [SEO alt text ΓÇö under 125 chars]
6. hook      : [one sentence connecting image to surrounding text]
```

**Brief produces:** purpose ┬╖ subject ┬╖ tone ┬╖ placement ┬╖ alt ┬╖ hook
**Brief does NOT produce:** camera style ┬╖ lighting ┬╖ style modifiers ┬╖ generation prompts ┬╖ dimensions
